## A. 치명적 — 기본 결과가 논문과 반대 결론을 냄

### A-1. 라우트 순위가 역전됨

| | 도구 기본 출력 (COO) | 논문 게재값 (Fig. 7a) |
|---|---|---|
| Steam cracking | **$751/t** (최고가) | **$680/t** (최저가) |
| MKM-SC₂H₄ | **$567/t** ← 초록색 "best" | $815–960/t 구간 |
| MKM-XC₂H₆ | $847/t | $815–960/t 구간 |
| Exp-Opt | $695/t | $815–960/t 구간 |

논문의 핵심 주장은 "Joule 가열은 자본비를 낮추지만 전기요금 때문에 판매가는 올라간다"입니다. 도구는 정반대로 MKM-SC₂H₄를 최저가로 초록 하이라이트합니다. 첫 화면이 논문을 반박하는 형태입니다.

### A-2. 원인 1 — Table S6는 TEA가 아니라 **LCA** 인벤토리

SI 구조를 보면 명확합니다.

- **Note 2 (TEA)**: 비용은 Aspen Economic Analyzer 출력 + Seider 유틸리티 단가. 인벤토리 표 없음.
- **Note 3 (LCA)**: Table S6 = "Inputs and outputs associated with the production of 1 kg of C₂H₄" — **LCIA용**.

SI 어디에도 Table S6 흐름이 TEA OPEX에 그대로 들어갔다는 서술이 없습니다. 도구는 서로 다른 두 Note를 가교해 OPEX를 재구성하는데, 벤치마크 경로에서 그 가교가 무너집니다:

```
3.41 kWh/kg × 610,000 t/y × 1000 = 2.080e9 kWh/y × $0.07 = $145.6 M/y
논문 게재값 (2.5절): 산업 벤치마크 전력비 = $37.6 M/y
→ 역산 단가 $0.0181/kWh (비현실적)
```

Joule 경로는 반대로 잘 맞습니다 — MKM-SC₂H₄ 3.58 kWh/kg → $152.9 M/y vs 논문 $145–154 M/y **거의 일치**. 즉 LCA의 steam 전력값에는 TEA가 전력비로 계상하지 않은 스팀·냉동 유틸리티의 전력등가가 섞여 있습니다. 벤치마크에만 **+$177/t**가 얹힙니다.

(MKM-XC₂H₆ $196 M/y, Exp-Opt $203 M/y도 논문 $145–154 M/y 범위를 넘습니다)

도구의 "한계 3번"에 이 위험이 한 줄 있지만, 경고 수준이 아니라 결론을 뒤집는 오차입니다.

### A-3. 원인 2 — "자본비는 SI에 없다"는 맞지만, **논문 본문에는 있습니다**

도구는 4경로 전부 `TBMC = 0`, "Aspen required", "Capital incomplete"로 둡니다. SI에 TBMC가 없다는 진단은 정확합니다. 그러나 논문 본문 2.5절에 **TCI가 게재**되어 있어 역산이 가능합니다:

```
TCI: $317 M (industry) / $242–254 M (MKM 2종) / Exp-Opt ≈ industry 수준
TOC = 2.5 × TBMC (가정 11)  →  TBMC ≈ TCI / 2.5
  steam $126.8 M · MKM-SC₂H₄ $96.8 M · MKM-XC₂H₆ $101.6 M · Exp-Opt $126.8 M
  → 연간 자본비 $24–32 M/y, 유지·보험 $18–24 M/y (합계 $69–91/t)
```

TCI와 TOC가 정확히 같다는 보장은 없으므로 "게재 TCI에서 역산한 기본값, 수정 가능"으로 태깅하면 됩니다.

### A-4. 두 가지를 고치면 논문을 재현합니다 — 가장 중요한 근거

```
steam:  $751/t  −$177/t (전력비 보정)  +$91/t (게재 자본비)  =  $665/t
                                              논문 게재값     =  $680/t   → 오차 2%
```

**이 대조표가 지금 도구에 전혀 없습니다.** 검증 패널을 넣으면 "재현 불가능한 반쪽짜리"에서 "논문을 2% 이내로 재현하는 도구"로 바뀝니다. 최우선 작업입니다.

### A-5. HP 스팀 10.7 kg/kg 단일 값이 MKM-XC₂H₆ 순위를 혼자 결정함

Table S6 전사는 정확하지만(10.7 맞음), 이 값이 이례적입니다:

| 경로 | HP steam | $25/t 기준 비용 |
|---|---|---|
| steam | 3.78 | $57.6 M/y |
| MKM-SC₂H₄ | 2.03 | $31.0 M/y |
| **MKM-XC₂H₆** | **10.70** | **$163.2 M/y** ← gross OPEX의 **29%** |
| Exp-Opt | 2.35 | $35.8 M/y |

스팀 희석이 가장 높은 쪽은 MKM-SC₂H₄(40 wt%)인데 HP 스팀은 오히려 최저입니다. MKM-XC₂H₆만 5배입니다. 이 값이 2.4 수준이었다면 COO가 **$847 → $640/t**로 순위가 다시 뒤집힙니다.

전사 오류는 아니므로 도구 잘못은 아니지만, 결과가 이 한 값에 매달려 있으므로 (a) 저자 확인, (b) 도구 내 "이 값이 결과를 지배함" 경고 표시를 권합니다.

### A-6. COO vs MSP — SI 자체가 두 용어를 혼용

SI 가정 5는 "**minimum selling price** of C₂H₄를 부산물 크레딧 가정 하에 계산", 가정 13은 "**Cost of C₂H₄ (COO)** = Eq. S8"이라 씁니다. 별도 MSP 산식은 SI에 없습니다.

즉 이 논문에서는 사실상 COO ≡ MSP로 쓰이고 있어, 도구가 Eq. S8로 COO를 계산해 $680/t와 비교하는 것은 **정당합니다**. (이전 리포트에서 이 점을 과하게 지적했는데 완화합니다.) 다만 원문이 혼용하고 있다는 사실을 도구 각주로 한 줄 남기면 독자 혼란이 없습니다.

## B. 신규 치명 — SI 가정 7(CFP 월 1회 교체)이 비용모델에 없음

이전 리포트에서 "CFP 수명을 테스트할 수 없다"고 적었는데, SI를 보니 더 심각합니다. **SI가 교체주기를 명시하고 있는데 도구가 이를 구현하지 않았습니다.**

> **가정 7.** "To attain near ideal temperature profile for MKM, we assume CFP completely occupies the tube. Despite relatively long time on stream performance, **we assume monthly replacement.**"

가정 6·7 + 본문의 CFP 사양(Freudenberg H23, 0.21 mm, 95 g/m²)으로 직접 계산됩니다:

```
CFP 벌크밀도 = 0.095 kg/m² ÷ 0.00021 m = 452 kg/m³
반응기 체적 (도구 기본 형상: 1000 kmol/h, 1000 °C, 1 bar, 100 ms)
  Q = 29.4 m³/s → V = 2.94 m³ → L = 1.81 m (144 tubes, D=0.12 m)
CFP 장입량 = 2.94 m³ × 452 = 1,330 kg
월 1회 교체 → 15,961 kg/y ≈ 16 t/y
  $20/kg  → $0.32 M/y = $0.52/t C₂H₄
  $50/kg  → $0.80 M/y = $1.31/t
  $100/kg → $1.60 M/y = $2.62/t
```

**도구가 현재 계산하는 값: 연 $112.**
(Table S6의 CFP 9.2E-9 kg/kg × 610,000 t/y × $20/kg — 같은 단가 기준으로 **2,844배 과소**)

Table S6의 CFP 값은 LCA용 질량배분 수치이지 TEA의 소모량이 아닙니다. 도구는 CFP 비용을 사실상 0으로 모델링하고 있어서, 논문이 스스로 지목한 핵심 리스크(material lifetime)가 화면에서 완전히 사라집니다.

**필요한 것**: `cfpPrice`(USD/kg)는 유지하되, 입력을 "교체주기(개월)"로 바꾸고 반응기 체적 × 밀도 × 연간 교체횟수로 계산. 그러면 형상 계산기(가정 6)와 비용모델(가정 7)이 연결되면서 지금 고립돼 있는 튜브길이 계산기가 비로소 쓸모가 생깁니다.

## C. 사용자 감도 — 논문이 요구한 항목이 없음

### C-1. 지금 있는 것
에탄가격 1차원 직선 스윕(100–400 $/t) + 전기요금 슬라이더. 곡선 4개가 평행 직선이라 정보량이 낮습니다.

### C-2. 논문이 명시적으로 요구한 감도항목

> "the TEA results carry inherent uncertainty related to **capital costs, operational stability, material lifetime, and scalability**. A sensitivity analysis on these parameters would be valuable in future studies." (본문 2.5절)

- **capital cost** — 슬라이더가 TBMC를 건드리지 않음. TBMC=0이면 감도곡선 전체가 자본비 없는 상태
- **material lifetime** — B절 참조. SI 가정 7에 "월 1회"라는 기준선이 있으므로 **교체주기 슬라이더로 즉시 구현 가능**
- **operational stability / scalability** — 가동률·온스트림 시간 입력 없음 (8000 h/y도 미노출)

### C-3. 권장 추가
1. **토네이도 차트** — TEA 도구 사실상 표준. 감도 패널 좌측 여백에 그대로 들어감
2. **전력원 프리셋** — 석탄 $1049 / 육상풍력 $694 / 해상풍력·태양광·수력 $710–835 (본문 2.5절, Fig. 8b). 게재 그림과 1:1 대조되므로 신뢰도 확보에 가장 효율적
3. **CFP 교체주기 슬라이더** (1–12개월)
4. x축 하드코딩 해제 — `sx=x=>L+(x-100)/300*pw`로 100–400 고정. 에탄가격에 800을 넣으면 마커만 400에 클램프돼 **KPI 값과 차트 마커가 다른 값**을 가리킴
5. Monte Carlo (선택) — 논문이 "불확실성 구간 없음"을 자인했으므로 P10/P50/P90 제시 시 부가가치 큼

## E. 시각화

### E-1. Cost stack 막대
- 막대는 **gross**를 그리는데 우측 총계는 **net COO** → 길이와 숫자가 불일치
- 크레딧이 막대 밖 초록 텍스트로만 있어 경로 간 비교 불가. **음수 세그먼트를 왼쪽으로 그리는 diverging 막대**로 해결
- TBMC=0이라 "Annualized capital"(남색) 폭이 0인데 범례에는 남아 있음
- 우측 회색 여백이 "데이터 없음"처럼 읽힘. 축·눈금이 없어 절대값 감각 없음
- O&M+labor(보라) 세그먼트가 1 px 수준으로 사실상 안 보임

### E-2. 감도차트
- steam `#00539f` vs MKM-SC₂H₄ `#2f7fc1` — **인접 파랑 2개**. 색각이상·흑백 인쇄에서 구분 불가. 실선/파선/점선 + 마커 병행 필요
- 툴팁이 `<title>` 기반이라 **호버 전용, 키보드 접근 불가**
- `role="img"`+`aria-label`은 있으나 데이터 테이블 대체본 없음

### E-3. 레이아웃·접근성
- "Feed and power intensity" 패널 하단 큰 빈 공간(좌측과 높이 불일치)
- 감도 패널 좌측 절반이 여백 — 토네이도 차트 자리로 적합
- 탭에 `aria-controls` 없음, 패널에 `aria-labelledby` 없음, 좌우 화살표 키 내비게이션 없음
- `fmt()`가 `toLocaleString(undefined, …)` 로케일 의존인데 통화기호는 `$` 하드코딩
